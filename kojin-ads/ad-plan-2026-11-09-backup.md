## 2) Recommended campaign structure

### Meta (Facebook + Instagram)

**Campaign A — Traffic / Crew signup (warm the list)**  
- **Objective:** Traffic (or Leads if using Instant Form; prefer site traffic to homepage Crew signup so WELCOME10 stays on-site).  
- **Optimization:** Landing page views → homepage with “Join the Kojin Crew, 10% off”.  
- **Ad set 1 — Broad JDM / streetwear (US, 18–34)**  
  - Interests / behaviors (stack loosely; let Meta find signal): JDM, drifting, Japanese streetwear, graphic tees, car culture, skate/streetwear brands, anime aesthetics (broad — not specific series), 2000s nostalgia, sim racing.  
  - Placements: Advantage+ placements, or manually Feed + Instagram Reels + Stories + Facebook Reels.  
- **Ad set 2 — PNW / Renton test (smaller share of budget)**  
  - Geo: Washington state + Portland metro (OR), or tighter: Seattle–Tacoma–Renton + Bellevue. Age 18–35. Same interest stack.  
  - Purpose: test whether local car-meet energy converts cheaper; not the main scale lever.  
- **Creative:** Meta variants M1–M3 below. Prefer single image or carousel of the 4 tees once mockups exist; flat art OK at start.  
- **CTA button:** Learn more (signup-focused) or Shop now (once checkout is live).

**Campaign B — Catalog / product traffic (only after password off + payments live)**  
- **Objective:** Sales or Traffic to product pages (start Traffic if pixel has little history).  
- **Ad set:** Same US 18–34 interest stack; exclude purchasers once you have a customer list.  
- **Creative:** Carousel of 4 synced tees, or one hero product at a time (Badge + Speed Identity first).  
- **Do not run Campaign B** until storefront password is removed, Shopify Payments works, and Printful billing is on.

**Pixel:** Install Meta Pixel + Conversions API on Shopify before launch. Standard events: PageView, ViewContent, AddToCart, InitiateCheckout, Purchase, plus a custom or Lead event on Crew signup if possible.

### TikTok

**Campaign T — In-Feed traffic**  
- **Objective:** Traffic (website visits) to homepage or collection.  
- **Audience:** US, 18–34. Interests: cars / JDM / streetwear / anime style / gaming-sim racing where available. Spark Ads later if organic clips perform.  
- **Placement:** TikTok automatic (In-Feed).  
- **Creative:** Must be video (or photo-mode slideshow). Use TikTok variants T1–T3 scripts below. 9:16, hooks in first 1–2 seconds, on-screen text, end card with WELCOME10 + store URL.  
- **Pixel:** TikTok Pixel on Shopify before spend.

**PNW note on TikTok:** Run a small geo-split only if daily budget ≥ ~$20 and Meta PNW test already shows promise; otherwise keep TikTok national US to avoid starving delivery.

## 5) Budget splits (examples — Griffin picks Saturday)

**Rule of thumb for small budgets:** start on **one** platform so delivery isn’t starved. Meta is usually the better first dollar for a new Shopify store with a signup offer; add TikTok once Meta has a clear winner or daily budget ≥ ~$20.

| Daily total | Suggested split | What to run |
|---|---|---|
| **$10/day** | **100% Meta** (TikTok off) | Campaign A only: one ad set (US 18–34), ads M1 + M2. Skip PNW split until budget grows. |
| **$20/day** | **$15 Meta / $5 TikTok** | Meta: Campaign A with M1–M3; optional tiny PNW ad set at $3–5 inside Meta. TikTok: T1 or T2 only (one creative). |
| **$40/day** | **$25 Meta / $15 TikTok** | Meta: Campaign A ($15) + soft launch Campaign B product traffic ($10) if checkout is live. Include PNW test (~$5 of Meta). TikTok: T1–T3 rotation. |

**Week-1 pacing:** Leave campaigns learning; don’t kill an ad before ~50 link clicks unless it’s clearly broken (wrong URL, password page, zero CTR). Pause losers after that signal, shift budget to the winner. Every campaign stays **paused** in Adspirer until Griffin OKs spend.

**Promo math to remember (not a performance claim):** tees are $28–$32; WELCOME10 ≈ $2.80–$3.20 off; shipping $8 standard — creative should set that expectation so checkout isn’t a surprise.

## 7) What to measure in week 1

Keep it simple — no invented benchmarks. Watch direction, not perfection.

**Funnel**
- Link clicks and landing-page views (are people reaching the open store?)
- Crew email signups (primary early goal if running M1 / T2)
- Add-to-cart and initiate-checkout (only meaningful after payments live)
- Purchases + revenue (if any); which product/page they came from

**Creative / channel**
- Which Meta ad (M1 vs M2 vs M3) gets more clicks and signups
- Which TikTok hook (T1 vs T2 vs T3) holds attention (3-second views / completes) and clicks through
- PNW ad set vs national US: cost per click and cost per signup — keep or kill the local test

**Health checks**
- Frequency climbing with no conversions → refresh creative
- Clicks but zero signups → landing/password/signup form issue
- Signups but zero carts → offer clarity, product page, or shipping surprise
- Any order failures → pause ads immediately and fix Printful / Payments
